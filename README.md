# 言宝 · dsh-photo-skin

[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 照片皮肤。九张人像按亮度从暗到亮排成一条强度轴，输入框旁的滑块同时切换背景照片与界面配色，并调节当前模型的思考档位。

![言宝](preview.webp)

## 特色

- **一条滑块，两种调节**：拖动切换照片和配色，松手把最近的思考档位提交给当前模型。
- **随亮度切换主题**：低档为深色玻璃，高档为白底深字，贴近 DSH 原生浅色界面。
- **跟随模型档位**：档位数量和名称直接读取当前模型，不写死。
- **每张照片单独配色**：配色由照片推导，配合遮罩与文字衬底保证正文清晰。
- **记住选择**：每个档位记住上次停留的照片，重启后回到原位。
- **可选效果**：背景遮罩、胶片颗粒、星尘粒子、空闲淡化，均可单独开关。
- **可换成自己的照片**：一个脚本完成转格式、排序和配色。

仓库自带 9 张示例照片，安装后即可使用。

## 安装

**要求**：DeepSeek Harness Desktop。

在 DSH 侧栏打开 **插件 → 添加插件**，输入以下任一地址，按提示重启 DSH：

- GitHub 仓库：`https://github.com/Down-tide/dsh-photo-skin`
- 本地目录：先 `git clone https://github.com/Down-tide/dsh-photo-skin.git`，再填入克隆目录的路径（需要换成自己的照片时，用这种方式）

也可以在完全退出 DSH Desktop 后，在克隆目录中执行：

```sh
dsh plugin --profile desktop add .
```

## 使用

### 滑块

滑块位于输入框右侧。拖动时实时预览照片；松手、键盘操作结束或失去焦点时，提交最近的思考档位。按 `Esc` 取消并回到拖动前的位置。

开启「绑定思考等级」时，若当前模型不支持思考档位或只有一个档位，不显示滑块。

### 档位与照片

九张照片按 1 / 2 / 3 / 3 分配给 off / low / high / max：

| 档位 | 照片 |
|---|---|
| off | 暮色初见 |
| low | 暖灯低语、碎光夜行 |
| high | 月下花影、沙白之昼、松荫素裙 |
| max | 静室玫瑰、蝶与薄雾、晨光初上 |

模型档位数不是 4 时按比例分配。开启「细分停点」时，从模型菜单切换档位会回到该档位上次选择的照片；未选过的档位显示该档位最亮的一张。

### 设置

入口：**设置 → 言宝**，或侧栏 **插件 → 言宝**。

| 设置 | 默认 | 说明 |
|---|---|---|
| 启用言宝 | 开 | 关闭后移除背景、配色和滑块，插件保持安装 |
| 背景遮罩 | 开 | 压暗照片以保证文字清晰；关闭后照片原样显示 |
| 颗粒质感 | 开 | 叠加细微的胶片颗粒 |
| 星尘粒子 | 开 | 背景浮现光点，强度越高越密；系统开启「减少动态效果」时自动关闭 |
| 空闲时淡化 | 开 | 模型空闲时照片变淡，生成时提亮，拖动滑块时全亮 |
| 绑定思考等级 | 开 | 滑块同时调节模型思考档位；关闭后只调外观 |
| 细分停点 | 开 | 滑块可停在九张照片中的任意一张；关闭后只停在档位刻度 |
| 隐藏输入框旁的滑块 | 关 | 隐藏后可在设置页调节 |
| 与「滑动变祖」互斥 | 开 | 启用言宝时自动停用「滑动变祖」，停用言宝时恢复 |

## 换成自己的照片

需要 macOS、Python 3 和 Node.js，并使用本地目录方式安装。

```sh
python3 -m pip install Pillow numpy

mkdir -p raw && cp ~/Pictures/我的照片/* raw/
python3 scripts/prepare-images.py
node scripts/build.mjs
```

完成后在 DSH 中按 `Cmd+Shift+R` 刷新。

- 脚本按亮度自动排序并生成配色，覆盖 `assets/` 中的照片和 `src/frames.js` 中的清单。
- 支持 HEIC、HEIF、JPEG、PNG、WebP、AVIF、TIFF、BMP、GIF；数量 2–24 张。
- 建议竖图宽度不低于 3200 px、横图高度不低于 2000 px，人物位于画面中间偏右（左侧会被侧栏遮挡）。
- 只替换部分照片：将新图按清单中的文件名命名（如 `05-denim-night.jpg`）放入 `raw/`，加 `--replace` 运行。
- 预览改动而不写入文件：加 `--dry-run`。
- 恢复示例照片：`git checkout assets/ src/frames.js lib/client.js`。

## 注意事项

- 本皮肤会修改 DSH 的主题配色和输入框右侧插槽，请勿与其他改动这些区域的皮肤同时启用。
- 本插件只在本机读取和显示照片，不会上传。
